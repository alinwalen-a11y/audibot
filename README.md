# AUDITOR-BOT 🤖
Agente Autónomo de Auditoría y Corrección de Código - DevSecOps

## ¿Qué hace?
Cuando abres un Pull Request, AUDITOR-BOT:
1. Analiza el código con patrones de seguridad
2. Detecta secretos expuestos, SQL Injection, TODOs y código lento
3. Corre benchmark de rendimiento
4. Comenta automáticamente en el PR con sugerencias
